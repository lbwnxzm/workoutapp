# BENFIT — deployable PWA

## Deploy
1. Sign in to Netlify: https://app.netlify.com/drop
2. Unzip `benfit-pwa.zip`.
3. Drag the `benfit-pwa` folder (the folder containing `index.html`) onto Netlify Drop.
4. Open the generated HTTPS URL.

## Install on iPhone
1. Open the deployed URL in Safari.
2. Tap Share → Add to Home Screen → Add.

## Local data
Workout logs and measurements are saved in this browser's localStorage. There is no account or cloud sync. Export JSON backups from the arrow icon or Progress → Export backup. Import a backup on another browser/device if needed. Do not clear website data unless you have exported a backup.

## Notes
- The programme starts 23 November 2026 and displays Week 1–8 based on the current date.
- Body composition baseline: 18 November 2026 (85.1 kg, 28.9% body fat, 34.4 kg skeletal muscle, 24.6 kg fat mass).
- The lower-body plan is deliberately conservative. Do not train through lower-back pain; stop any movement that aggravates symptoms and seek clinical assessment for persistent pain.
